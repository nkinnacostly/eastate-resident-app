# Everything on this site is public marketing copy about a product we want
# recommended. There is nothing here worth withholding from a crawler, so the
# answer to all of them is yes.
#
# WHY THE NAMED GROUPS BELOW EXIST, GIVEN "User-agent: *" ALREADY ALLOWS ALL
#
# Three reasons, and none of them is "it makes crawling work":
#
#   1. A robots.txt parser applies exactly ONE group per crawler — the most
#      specific match — and ignores the rest. So the day someone adds a
#      `Disallow:` under `*` to keep an admin path out of Google, every AI
#      crawler would silently lose access too. The named groups make that
#      mistake impossible to make by accident.
#   2. Google-Extended and Applebot-Extended are opt-OUT controls that have no
#      "allow" semantics at all. Listing them is documentation: it records that
#      their absence is a decision, not an oversight, so nobody adds them as
#      blocks later without reading this.
#   3. It states intent in the one place an operator looks first.
#
# The grouping is by JOB rather than by company, because the job is what
# decides whether allowing it helps us. See the note above each block.

User-agent: *
Allow: /

Sitemap: https://myestateaccess.com/sitemap.xml
